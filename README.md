# 🌌 Ahmed Gamal — Personal Portfolio

> A high-performance, cinematic developer portfolio built with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS**, and **Framer Motion**. Features an ambient video background, interactive project accordion, custom tech stack showcases, and direct links to live applications & GitHub repositories.

---

## ✨ Features

- 🎥 **Cinematic Dark OLED Theme**: Ambient video background with dynamic dark gradient overlays and subtle noise texture.
- 📱 **Interactive Project Accordion**: Expanding visual accordion component with category filtering (`All`, `Mobile`, `Web`), smooth hover triggers, and touch screen support.
- 🚀 **Live App & Repository Links**: Quick action modal with direct links to live deployed applications and open-source GitHub repositories.
- 💼 **Timeline & Education Matrix**: Dedicated sections showcasing professional software engineering experience, education, and published research.
- ⚡ **100% Fully Responsive**: Pixel-perfect layout optimization across mobile phones, tablets, laptops, and ultra-wide displays.
- 🛠️ **TypeScript & Modern Stack**: Strictly typed components, Next.js App Router, Lucide Icons, and Framer Motion micro-interactions.

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js 18+** and **pnpm** installed.

```bash
npm install -g pnpm
```

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AhmedGamalFarouk/myPortfolio.git
   cd myPortfolio
   ```

2. **Install dependencies**:
   ```bash
   pnpm install
   ```

3. **Run the development server**:
   ```bash
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Build & Deployment

To create an optimized production build:

```bash
pnpm build
```

This project is deployed on **Vercel** with automatic continuous deployment (CD) enabled on pushes to the `main` branch.
